# Internship Application Assistant

A small FastAPI CRUD API for recording company, role, deadline, status, and notes.

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open /docs to explore the API. The MVP stores records in a local JSON file; use a database, authentication, and backups before multi-user deployment.

## Live deployment

- **Frontend:** https://assisnmanrt-for-internship-frontend-vijayjangids-projects.vercel.app
- **Backend API:** https://internship-assistant-api.onrender.com
- **API docs:** https://internship-assistant-api.onrender.com/docs

> Deployment is an MVP. Configure required secrets (if any), add authentication, and use durable database storage before production use.
